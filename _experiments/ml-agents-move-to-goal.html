Overview

After experimenting with Q-learning and MCTS for Skit Gubbe, I turned my focus to Unity's ML-Agents package and started learning how to teach an AI agent to move through obstacles using reinforcement learning: giving it rewards when it completes the challenge and taking points away when it fails.

Iterations

A fixed course

I began by making a platform, an agent, a goal and walls surrounding the platform. I gave the agent two observations: the goal's position and its own. The first simulations went well, and it only took a minute for the agent to figure out where it had to go.

Random start positions

On that first course, the positions of the agent and the goal stayed the same every episode. I then started randomizing both positions, so the agent had to learn to navigate to the goal from anywhere.

Wall obstacles

After a few runs I added wall obstacles to the course, making sure neither the agent nor the goal intersected with these walls at the start of each episode.
